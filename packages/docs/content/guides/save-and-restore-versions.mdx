---
title: Save and restore versions
description: Keep snapshots of your project and go back to any of them.
---

Open **History** (under Overview in the project tree, or press **Ctrl+S**).

- **Save version**: type what changed (*Added the berry bun*) and click the button. Blocksy saves
  the whole project folder as a version on this computer.
- **Restore**: hover a version and click **Restore**. The project goes back to that version as
  one step, so **Ctrl+Z** brings back what you had.

<Callout title="It's git">
Versions are git commits in your project folder, so any git tool can read them, and GitHub sync
(coming in v0.7) builds on them. You need git installed; Blocksy tells you if it isn't.
</Callout>
