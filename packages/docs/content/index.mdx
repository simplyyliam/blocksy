<BlockDemo caption="Your first block, live. Drag to turn it." />

Blocksy writes a real Fabric mod for you. Every field you change shows the Java it
becomes, and the **Code** tab shows every file Blocksy writes, so you can learn the code
at your own pace without ever being stuck on it.
