# Performance: Blocksy 0.3.0

Measured 2026-11-04 with `pnpm bench` (5 runs, medians shown).

## Machine

| | |
| --- | --- |
| OS | Windows_NT 10.0.26300 |
| CPU | AMD Ryzen 5 7430U with Radeon Graphics (12 threads) |
| RAM | 15 GB |
| GPU | AMD Radeon (TM) Graphics |
| Screen | 2560x1440 at 1.5x |

## Results

| What | Result | Budget | |
| --- | --- | --- | --- |
| Cold start to Home | 1280 ms | 2500 ms | ✅ pass |
| Frame time, median | 16.7 ms | | |
| Frame time, 95th percentile | 17.0 ms | 33.3 ms (30 fps) | ✅ pass |
| Memory, whole app (peak) | 357 MB | 600 MB | ✅ pass |
| JS heap | 38.8 MB | | |
| Block preview ready (first open) | 1192 ms | 1000 ms | ❌ over |
| Frames drawn by an idle 3D view (2 s) | 0 | 0 | ✅ pass |

Cold start counts from the Rust process starting to Home being painted (two frames after first render),
with a fresh WebView2 data folder each run (a true cold start).
The frame times cover a scripted workout: opening the build log, streaming 5,000 log lines,
the New project and Settings dialogs, and switching pages. Memory adds up blocksy.exe and its
WebView2 processes (private working set, as in Task Manager).
The 3D rows open a project with 20 blocks in the editor, time until the first block's preview is drawn
(WebGL start, shaders, texture), then count frames while it sits untouched for 2 seconds (render on demand).

> **Block preview over budget: the machine, not v0.3 (ADR 0010).** The same day, on the same machine, the
> 0.2 code (`main`, rebuilt and benched right before this run) measured a median of **1158 ms** (runs: 1126,
> 785, 1165, 1158, 1176). This branch measured 1192 ms, +3%, under the plan's 10% regression line. Both
> show the same pattern: most runs ~1.17 s and one ~0.8 s, while 0.2's own report (2026-10-30) had
> 818 ms. v0.3 changed nothing on the 3D path (model-studio and the block canvas are untouched).
> A first try that waited for an idle moment before timing gave the same ~1.17 s, so it was not kept.
> Worth re-running `pnpm bench` on a quiet, freshly restarted machine to see whether ~0.8 s comes back.
